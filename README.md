# Workstation モバイル

Mac の Workstation の「毎日確認」「ガントチャート」「カレンダー」をスマホで使うための PWA（ホーム画面に追加して使う Web アプリ）です。

- サーバー・データベースは使いません。データはスマホの中（IndexedDB）にだけ保存し、外へは送りません。
- Mac とはファイル（JSON）で同期します。AirDrop などで受け渡します。
- オフラインでも開けます（service worker）。
- スマホだけでも使えます。習慣・プロジェクト・タスクはスマホで作れて、あとから Mac に取り込めます。

## 公開のしかた（GitHub Pages・無料）

1. GitHub で新しいリポジトリ（公開）を作り、この `mobile/` フォルダの中身をそのまま入れる
   （データはファイルに入っていないので、コードを公開しても中身は見えません）
2. リポジトリの Settings → Pages → Branch を `main`・フォルダ `/ (root)` にして保存
3. 出てきた URL を iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

> ホーム画面に追加したアプリで使ってください。Safari のタブのままだと、しばらく使わないとデータが消されることがあります。

### 新しくしたとき

`sw.js` の `VERSION`（例 `ws-mobile-v1` → `ws-mobile-v2`）を上げてから公開します。アプリを1回開くと裏で新しいファイルを取り込み、次に開いたときから新しくなります。

## 同期のしかた

| どちらへ | すること |
|---|---|
| Mac → スマホ | Mac：設定 →「スマホ用に書き出す」→ ファイルをスマホへ → スマホ：同期 →「ファイルを取り込む」 |
| スマホ → Mac | スマホ：同期 →「Macへ送る」（共有シートで AirDrop）→ Mac：設定 →「スマホの変更を取り込む」 |

- スマホでした変更は「送っていない変更」として残り、Mac で取り込んだあとに Mac から受け取ると消えます。
- 同じファイルを何度取り込んでも二重にはなりません（変更ごとにIDが付いています）。
- 学習計画などをまとめて入れる「追加用のファイル」（`kind: "changes"` の形）も「ファイルを取り込む」で入ります。スマホでした変更として扱うので、「Macへ送る」で Mac にも入ります（Mac の「スマホの変更を取り込む」で直接入れることもできます）。
- 同じタスクを Mac とスマホの両方で変えたときは、あとから取り込んだスマホの変更が入ります（変えた項目だけ）。
- 繰り返しのタスクをスマホで完了にすると、次の回は Mac で取り込んだときに作られます。
- スマホで作った習慣・プロジェクトと同じ名前のものが Mac にあれば、新しく作らずそれにまとめます。
- タイマー連動・ノートとのつながり・繰り返しの設定・プロジェクトの削除は Mac で行います。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面（色・角丸・ボタンは Mac 版と同じ） |
| `app.js` | 画面の動き（毎日確認・ガント・カレンダー・同期・タスクの編集） |
| `model.js` | データの形と計算（受け取り・変更の記録・習慣の連続日数など）。Mac 側のテスト（`npm test`）からも使っています |
| `icons.js` | アイコン（Lucide、Mac 版と同じもの） |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA の設定とアプリのアイコン |
